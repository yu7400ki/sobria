## NotFound

```ts
class NotFound extends Error {
  constructor();
```

## notFound

ページが見つからないことを表す値を返す。返した値をシェルの中で投げると、404 のレスポンスになる。シェルの後では、`<Errored>` が受け止める。

```ts
const notFound: () => NotFound;
```

## Redirect

`location` への移動を表す。`location` が相対 URL でも http や https の URL でもなければ、作成するときにエラーを投げる。

```ts
class Redirect extends Error {
  readonly location: string;
  readonly status: RedirectStatus;
  constructor(location: string, status: RedirectStatus);
}
```

## redirect

`location` への移動を表す値を返す。返した値をシェルの中で投げると、`status` のリダイレクトのレスポンスになり、シェルの後で投げると、ブラウザで移動させる。`location` には、相対 URL か、http か https の URL を指定する。それ以外のスキームを指定すると、エラーを投げる。

```ts
const redirect: (location: string, status?: RedirectStatus) => Redirect;
```

## RedirectStatus

リダイレクトのステータスを表す。

```ts
type RedirectStatus = 301 | 302 | 303 | 307 | 308;
```

## renderToResponse

`node` を描画し、シェルが揃った時点で、本文を送り続ける Response を返す。シェルの中で投げた `redirect()` はリダイレクトのレスポンスにし、Response はそのまま返す。`notFound()` は `notFound` のページを 404 で返し、ページが無ければ `Not Found` のテキストを 404 で返す。どの `<Errored>` も受け止めなかったエラーは、`error` のページを 500 で返し、ページが無ければ reject する。`notFound` のページの描画で投げたエラーには `error` のページを使用する。`error` のページの描画で投げた値は、ページを使用せずに、`redirect()` と `notFound()` と Response を同じ規則で扱い、それ以外では reject する。

```ts
function renderToResponse(
  node: unknown,
  { notFound, error, ...options }?: ResponseOptions,
): Promise<Response>;
```

## renderToStream

`node` を、文書の全体の HTML のストリームとして描画する。シェルを送った後に、後送りの境界を届いた順に送る。

## getServerFnResult

ページを描画するきっかけになったリクエストで、サーバー関数 `fn` が返した値を返す。対象のリクエストは、フォームの送信と、JS からの呼び出しの後に、送信したページや呼び出したページを描画するリクエストである。そのリクエストで `fn` が値を返していなければ、別のサーバー関数が値を返していても `undefined` を返す。`fn` が Response かストリームを返したときと、サーバー関数のミドルウェアかルートの `middleware.ts` が handler の後で例外を投げたときも `undefined` を返す。

```ts
function getServerFnResult<In, R, M extends ServerFnMethod>(
  fn: ServerFn<In, R, M>,
): ResultOf<R> | undefined;

type ResultOf<R> = Exclude<Awaited<R>, Response | AsyncIterable<unknown>>;
```

## forRoute

`hono/factory` の `defineHandler` を、ファイルの形のパスが `_route` のルートの型で持つオブジェクトを返す。その `defineHandler` で定義した handler の `c.req.param()` は、`_route` のパラメータを `string` で返す。

```ts
function forRoute<Route extends keyof RouteParams>(
  _route: Route,
): Pick<Factory<any, HonoPath<Route & string>>, "defineHandler">;

type HonoPath<Path extends string> = Path extends `${infer Part}/${infer Rest}`
  ? `${HonoPart<Part>}/${HonoPath<Rest>}`
  : HonoPart<Path>;

type HonoPart<Part extends string> = Part extends `[...${infer Name}]`
  ? `:${Name}{.+}`
  : Part extends `[${infer Name}]`
    ? `:${Name}`
    : Part;
```

## defineServerFn

1 段目のオプションを受け取り、ミドルウェアと handler からサーバー関数を作成する関数を返す。サーバーで呼び出すと、処理中のリクエストの Context を使用して、ミドルウェア、入力の検証、handler の順に実行する。ミドルウェアが `next()` を呼ばずに Response を返したら、その Response を投げる。Standard Schema の検証が失敗したら、`issues` を持つ `SchemaError` を投げる。

オプションを省略して、ミドルウェアと handler からサーバー関数を作成する。

```ts
function defineServerFn<
  V extends Validation = never,
  Method extends ServerFnMethod = typeof defaultServerFnMethod,
>(
  options: ServerFnOptions<V, Method>,
): <M extends AnyMiddleware[], R>(
  ...args: [...middleware: M, handler: ServerFnHandler<M, OutputOf<V>, R>]
) => ServerFn<InputOf<V>, R, Method>;

function defineServerFn<M extends AnyMiddleware[], R>(
  ...args: [...middleware: M, handler: ServerFnHandler<M, undefined, R>]
): ServerFn<undefined, R, typeof defaultServerFnMethod>;

const defaultServerFnMethod = "POST";

type AnyMiddleware = MiddlewareHandler<any, any, any>;

type ServerFnHandler<M extends AnyMiddleware[], In, R> = (
  c: Context<IntersectNonAnyTypes<MiddlewareEnvs<M>>>,
  args: {
    input: In;
  },
) => R;

type MiddlewareEnvs<M extends AnyMiddleware[]> = {
  [K in keyof M]: M[K] extends MiddlewareHandler<infer E, any, any> ? E : never;
};

type OutputOf<V> = [V] extends [never]
  ? undefined
  : V extends StandardSchema<any, infer O>
    ? O
    : V extends (...args: never[]) => infer O
      ? Awaited<O>
      : never;

type InputOf<V> = [V] extends [never]
  ? undefined
  : V extends AnySchema
    ? "types" extends keyof V["~standard"]
      ? NonNullable<V["~standard"]["types"]>["input"]
      : OutputOf<V>
    : V extends (value: infer I, c: Context) => unknown
      ? I
      : never;

type AnySchema = StandardSchema<any, any>;
```

## ServerFn

入力の型が `undefined` なら、入力を省略して呼び出せる。

```ts
type ServerFn<In, R, M extends ServerFnMethod = ServerFnMethod> = ([In] extends [undefined]

```
